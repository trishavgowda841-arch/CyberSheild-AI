# 🛡️ CyberShield AI

CyberShield AI is an AI-powered phishing email detection platform built using Machine Learning, Python, and Streamlit.

The system analyzes email content, sender information, URLs, suspicious keywords, and social engineering indicators to detect potential phishing attacks.

---

##  Features

- AI-powered phishing detection
- Threat Score (0-100)
- Sender Email Analysis
- URL Reputation Analysis
- Suspicious Keyword Detection
- Risk Classification
- Security Recommendations
- Threat Intelligence Dashboard
- Downloadable Threat Reports
- Dark Cybersecurity-Themed Interface

##  Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/CyberShield-AI.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
